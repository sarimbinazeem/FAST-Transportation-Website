# 🚍 FAST Point Transportation Website

A complete **HTML + CSS + JavaScript** web project built for an ICT course, designed to digitalize and simplify the transportation system of a university.  
The system includes route listings, driver details, search functionality, UI animations, dark mode, and more.

---

## 📌 Features

### 🌐 Main Pages
- **Home Page**
  - Loading animation  
  - Image slideshow  
  - Buttons for *Nadeem* and *Jadoon* bus services  
  - Responsive navigation bar  

- **Nadeem Bus Service Page**
  - List of routes  
  - Search bar to filter routes  
  - Clickable route cards  

- **Jadoon Bus Service Page**
  - List of routes  
  - Search functionality  
  - Clickable route cards  

- **About Us Page**
  - Information about university transportation  
  - Mission & purpose  

- **Contact Page**
  - Contact form with JavaScript validation  

---
